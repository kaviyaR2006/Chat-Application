
# Java Chat Application

## Project Description
A real-time chat application developed using Java.
It allows multiple users to communicate through
a client-server architecture.

## Technologies Used
- Java
- Java Swing
- AWT
- Socket Programming
- Multithreading

## Features
- User Management
- Real-Time Messaging
- Group Chat
- File Sharing
- Message Searching
- Chat Analytics

## Project Structure
- Server.java - Handles client connections
- Client.java - Provides the chat interface

## How to Run

1. Open the project in VS Code.
2. Compile Server.java and Client.java.
3. Start the server first.
4. Run the client in another terminal.
5. Enter a username and start chatting.
